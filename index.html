kill switch

5 safety nets.
Zero IP leaks.

The kill switch blocks all outbound traffic the moment the VPN drops. Five independent recovery paths ensure the firewall is always restored — even on crash, signal, or forced restart.

01
closeEvent
Restores firewall when the app window is closed via the X button.
02
atexit
Registered handler restores on any normal Python process exit.
03
Startup Restore
Next app launch detects dirty state and restores firewall before GUI opens.
04
Task Scheduler
Windows Task Scheduler task runs MirageFirewallRestore on every system boot.
05
Signal Handlers
SIGTERM and SIGHUP handlers catch signal-based termination and restore rules.
